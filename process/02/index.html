PDF Desktop App — Tauri v2 + pdf.js

Context

Build a minimal desktop PDF viewer for Linux using pdf.js for rendering. The app should produce the smallest possible distributable — hence Tauri v2 (system WebKitGTK webview, ~5-15MB AppImage vs Electron's ~150MB+). Primary distribution: AppImage.

Tech Stack

  • Tauri v2 — Rust backend, system webview frontend
  • pdf.js — Mozilla's PDF rendering library
  • Vanilla HTML/CSS/JS — no frontend framework (smallest bundle)
  • npm (via volta) — package management
  • @tauri-apps/cli — Tauri CLI as npm devDependency

  • capabilities/default.json — permissions (dialog:open, fs:read, etc.)
  • src/lib.rs — minimal Tauri app entry point
  • src/main.rs — binary entry point

3. Build the frontend (src/)

  • index.html — toolbar (open, prev/next page, zoom, page counter) + canvas container
  • style.css — dark theme, responsive layout, toolbar styling
  • main.js — core logic:
  • Initialize pdf.js with worker

  • Page navigation (prev/next/go-to)
  • Zoom controls
  • Keyboard shortcuts (arrows, +/-, Ctrl+O)

  • pdf.js worker from node_modules — copy or reference from pdfjs-dist package
  • CLI arg handling — so PDFs can be opened via "Open with" in file managers

dropping a PDF on the window does not open

2 edit · 1 read · 1 task · 1 bash

The issue is clear — Tauri v2 changed the drag-drop API entirely. The old tauri://file-drop event doesn't exist. The correct API is getCurrentWebview().onDragDropEvent() with a type: 'drop' payload containing paths.

Since we use withGlobalTauri: true (no npm imports), the API is on window.__TAURI__.webview.

The binary built fine (the AppImage failure is the same linuxdeploy strip issue — needs NO_STRIP=true). The fix is in place: the binary at src-tauri/target/release/pdf-js-app has the updated code.

What changed: Replaced the old Tauri v1 tauri://file-drop event listener with the correct Tauri v2 API — getCurrentWebview().onDragDropEvent(), listening for event.payload.type === "drop" which provides event.payload.paths with the dropped file paths.

You can test by running the binary directly:

./src-tauri/target/release/pdf-js-app
