Automated Testing Strategy for PDF Viewer

Context

The app is a Tauri v2 desktop PDF viewer with a vanilla JS frontend. An agent needs to verify UI features are working after changes. The Tauri API surface is small (4 call sites: dialog, fs, webview, core), so we can test ~90% of features by serving the frontend in a regular browser with mocked Tauri APIs.

Approach: Playwright + Static Server + Tauri API Mocks

Serve src/ via a static HTTP server, inject a mock window.__TAURI__ via page.addInitScript(), and test all UI interactions against real pdf.js rendering in a headless browser. No Rust build, no Xvfb, runs in seconds.

2. Generate test PDF fixtures (tests/generate-fixtures.js)

Use pdf-lib to create 3 small PDFs programmatically:

  • simple.pdf (3 pages): Each page has text "Page 1", "Page 2", "Page 3" using standard font. Covers: page navigation, page count, zoom, thumbnails.
  • searchable.pdf (2 pages): Contains "The quick brown fox", "FOX" (case test), "résumé" vs "resume" (diacritics), repeated "word word word" (whole word). Covers: find bar features.
  • with-outline.pdf (3 pages): Same as simple but with a bookmark outline (Chapter 1 → page 1, Chapter 2 → page 2, Chapter 3 → page 3). Covers: outline sidebar, bookmark navigation.

Commit the generated PDFs so tests run without an extra step. Include the script for reproducibility.

3. Create Tauri API mock (tests/tauri-mock.js)

Export a function injectTauriMock(page, fixturePath) that: 1. Reads the fixture PDF as a base64 string 2. Calls page.addInitScript() to define window.__TAURI__ before the app loads: - dialog.open() → returns a fake path string - dialog.save() → returns a fake output path - fs.readFile() → returns the PDF bytes (decoded from base64) - fs.writeFile() → records the call (for save assertions) - webview.getCurrentWebview().onDragDropEvent() → no-op - core.invoke() → returns empty args 3. Exposes page.evaluate(() => window.__tauriMock__) for inspecting mock state (e.g., what was written to fs)

/**
 * Inject a mock window.__TAURI__ into the page before the app loads.
 * @param {import('@playwright/test').Page} page
 * @param {string} fixturePath - path to the PDF fixture relative to project root
 */
export async function injectTauriMock(page, fixturePath) {
  const absolutePath = resolve(fixturePath);
  const pdfBytes = readFileSync(absolutePath);
  const pdfBase64 = pdfBytes.toString('base64');
  const fakePath = `/mock/${fixturePath.split('/').pop()}`;

  await page.addInitScript(({ pdfBase64, fakePath }) => {
    // Decode base64 to Uint8Array
    const binaryStr = atob(pdfBase64);
    const bytes = new Uint8Array(binaryStr.length);
    for (let i = 0; i < binaryStr.length; i++) {
      bytes[i] = binaryStr.charCodeAt(i);
    }

    // Mock state for assertions
    window.__tauriMock = {
      dialogOpenCalled: false,
      dialogSaveCalled: false,
      fsWriteCalls: [],
      fakePath,
    };

    window.__TAURI__ = {
      dialog: {
        open: async (options) => {
          window.__tauriMock.dialogOpenCalled = true;
          window.__tauriMock.dialogOpenOptions = options;
          return fakePath;
        },
        save: async (options) => {
          window.__tauriMock.dialogSaveCalled = true;
          window.__tauriMock.dialogSaveOptions = options;
          return '/mock/output.pdf';
        },
      },
      fs: {
        readFile: async (path) => {
          return bytes.buffer;
        },
        writeFile: async (path, data) => {
          window.__tauriMock.fsWriteCalls.push({ path, dataLength: data.byteLength });
        },
      },
      webview: {
        getCurrentWebview: () => ({
          onDragDropEvent: async (callback) => {
            // Store callback for potential test use
            window.__tauriMock.dragDropCallback = callback;
          },
        }),
      },
      core: {
        invoke: async (cmd) => {
          if (cmd === 'plugin:cli|cli_matches') {
            return { args: {} };
          }
          return {};
        },
      },
    };
  }, { pdfBase64, fakePath });
}
